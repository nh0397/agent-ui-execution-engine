# Scripted verification of the human recorder

This is an automated test of the real human-recording mechanism, not evidence that a person demonstrated a workflow. It used the real browser and local synthetic app. Thirteen supported gestures generated 26 redacted before/after screenshots and WORKFLOW.md. The draft contains 14 replay actions (focus-only clicks are documented but omitted from execution; output reads are explicit).

The resulting human-source capability replayed successfully for another customer/address with the model HTTP transport disabled in the test. A separate full-stack test exercised dashboard recording, review, publication, generated inputs, replay, and downloading this document bundle.

Example input values are not persisted in the capability or text evidence. Images mask fields and configured sensitive regions before persistence. This fixture remains outside the runnable catalog.
